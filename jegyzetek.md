# 📝 Jegyzetek

Ez az oldal a dokumentáció használatához és karbantartásához tartalmaz rövid, gyakorlati információkat.

## Miért Docsify?

- gyorsan elindítható
- markdown alapú
- egyszerűen bővíthető új oldalakkal

## Futtatás helyben

```bash
npx docsify serve .
```

Ezután a dokumentáció böngészőből helyben megnyitható.

## Ajánlott szerkesztési szabályok

- egy oldal egy témát fedjen le
- a címek legyenek egyértelműek
- minden fontosabb fogalomhoz legyen rövid példa
- a hosszú blokkok helyett rövid bekezdések legyenek

## Javasolt oldalstruktúra

1. Rövid bevezetés
2. Alapfogalmak
3. Egyszerű példák
4. Összefoglalás vagy következő lépés
