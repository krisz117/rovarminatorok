# 🌐 Web fejlesztés

A webfejlesztés célja, hogy böngészőben futó, használható és áttekinthető oldalakat vagy alkalmazásokat készítsünk. A legtöbb alap projekt három technológiára épül: HTML, CSS és JavaScript.

## A három alaptechnológia

### HTML

Az oldal szerkezetét adja. Ezzel írjuk le a címeket, bekezdéseket, gombokat és egyéb elemeket.

### CSS

Az oldal megjelenését szabályozza. Színek, térközök, betűméretek és elrendezések tartoznak ide.

### JavaScript

Az oldal működéséért felel. Eseményeket kezel, adatokat módosít, és interaktívvá teszi a felületet.

## Egyszerű példa

Az alábbi HTML egy nagyon egyszerű oldalrészlet:

```html
<h1>Hello Web</h1>
<p>Ez egy egyszerű weboldal.</p>
<button>Kattints ide</button>
```

## Mire érdemes figyelni?

- A HTML legyen szemantikusan helyes.
- A CSS maradjon átlátható és következetes.
- A JavaScript csak azt a logikát tartalmazza, amire tényleg szükség van.
