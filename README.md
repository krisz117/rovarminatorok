## Használati tippek

- A bal oldali menüvel gyorsan válthatsz a témák között.
- A keresővel azonnal megtalálhatod a kulcsszavakat.
- A sötét és világos nézet között a jobb felső kapcsolóval válthatsz.

## Javasolt tanulási útvonal

Ha kezdőként használod ezt a dokumentációt, először a webes alapokkal indulj, utána nézd át a JavaScript oldalt, majd hasonlítsd össze az itt látott példákat a saját kódoddal.
